# Start here

This workshop uses Codex as a research assistant. You can complete the student activities with ordinary language; the assistant handles the browser and any code it needs.

## Before the session

1. Open Codex and its built-in browser in the right-side view.
2. Sign in to your own university library in that browser if an article requires institutional access. Participants from ETH Zurich, the University of Zurich, and the University of Basel may see different access results.
3. Open Zotero desktop, make a collection named `test`, and select it.
4. Install the official Zotero Connector in Codex's built-in browser. The instructor will provide the course skill that guides Codex's save action.
5. For the Connector exercise, enable Codex's CDP browser access in Computer Use settings. This gives the assistant browser developer controls; use the setting for the exercise on pages you trust.

## Readiness check

Ask Codex to open a publisher article page in the right-side browser and identify the title, DOI, publication date, and access label. Check that Zotero is running with `test` selected. The exercise can proceed when Codex can see the article page and the official Connector is installed in the same browser.

If your institution does not subscribe to a chosen article, use a different article or an openly accessible example. The lesson's verification steps are the same.
